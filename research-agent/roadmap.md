# New Loop Research Agent Roadmap

## Overview

New Loop Research Agent is an AI-native research companion designed to support the exploration, analysis, and evolution of The New Loop Theory.

It is not intended to replace human judgment.
Instead, it helps researchers structure observations, model systems, and accelerate theoretical exploration.

---

Status:
Planning

Build the foundational knowledge required for AI to understand and apply The New Loop Theory.


Deliverables:

- On-ramping: The New Loop Theory
